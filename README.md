# LoFiWeb

LoFiWeb is a "cozy productivity" web application designed to provide an immersive, distraction-free environment for users to focus, study, or relax.

## Key Features

- **LoFi Music Player**: High-quality LoFi tracks with smooth crossfading and persistent playlist management.
- **Ambient Sound Engine**: Layerable background sounds including rain, cafe ambiance, and keyboard noises.
- **Dynamic Visualizer**: A high-performance canvas-based audio visualizer that reacts to music and user interactions.
- **Atmospheric Environments**: High-definition video backgrounds with crossfade transitions between scenes.
- **Integrated Productivity Tools**:
  - Pomodoro-style Focus Timer
  - Minimalist Todo List widget
- **Customizable Experience**: Personalized themes, secondary colors, and UI modes (Light/Dark/Auto).
- **Persistent State**: Your preferences, playlists, and even the current state of your timer are saved across sessions.

## Technology Stack

- **Framework**: [Next.js 16](https://nextjs.org/) (App Router)
- **UI Library**: [React 19](https://react.dev/)
- **Styling**: [Tailwind CSS 4.0](https://tailwindcss.com/)
- **State Management**: [Zustand](https://github.com/pmndrs/zustand) with Persistence
- **Animations**: [Anime.js](https://animejs.com/) and [Tailwind Animate](https://github.com/jamiebuilds/tailwind-animate)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Audio/Visual**: Web Audio API and HTML5 Canvas
